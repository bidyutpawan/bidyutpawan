# Text to Insta Reel Video Converter

## Features
- Convert text to video with audio for Instagram Reels.
- Select from multiple templates.
- Simple frontend and backend architecture.

## How it works
1. Enter your text.
2. Choose a template.
3. Click "Generate Video".
4. The resulting video is displayed.

## Setup
1. `cd server && npm install && npm start`
2. `cd client && npm install && npm start`
3. Visit `localhost:3000` to access the frontend.

## Extending functionality
- Integrate with Text-to-Speech (TTS) API for audio generation.
- Use FFmpeg or similar for video composition.
- Add more templates and animations.
